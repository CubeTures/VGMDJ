# VGMDJ

A multifaceted tool for operating a video game music library.

## Features

- Download from KHInsider
- Hide disliked songs
    - Boo endpoint to hide and current song
        - Tip: Leverage this using client-side macros
    - Automatically hide songs below a given length (goodbye sfx!)
- Set cover art of artists, albums, and songs
